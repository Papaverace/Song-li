# Song-li
Thuyết trình bài sóng 11 


## Game trong bài thuyết trình

- [Máy Gacha Câu Hỏi](https://papaverace.github.io/Song-li/): chơi giữa bài, ôn sóng ngang và sóng dọc.
- [Chợ Đen Câu Hỏi](https://claude.ai/artifact/HqYK6AcAjDYmwHMEsvnkdQ): chơi cuối bài, đấu giá câu hỏi và tổng kết cả 4 phần. Mã nguồn ở thư mục [`cho-den-cau-hoi`](cho-den-cau-hoi); tải về rồi mở `index.html` là chơi được.
